# Prep: Set up a password manager

**Why it matters:** Most account takeovers come from reused passwords leaking in someone else's breach. One manager means a unique password for every account and only one passphrase to remember. Every later security task builds on this one.

**Time:** ~75 min (20 setup + 45 accounts + 10 log)

## Pick one (don't overthink it)
- **Bitwarden:** free, open source, good enough for everyone. https://bitwarden.com/download/
- **1Password:** paid (~$3/mo), very polished. https://1password.com/downloads/
- Getting started guides: https://bitwarden.com/help/getting-started-webvault/ · https://support.1password.com/explore/get-started/

## Steps
1. **Create the master passphrase.** 4–6 random words, e.g. `copper-violin-harbor-mango-tide`. It must not be used anywhere else. Write it on paper; keep it at home, not in your wallet.
2. **Install it** on your personal phone + personal laptop, plus the browser extension. Never on a work device.
3. **Turn on 2FA for the manager itself** (authenticator app). Save the recovery code on paper next to the passphrase.
4. **Move in your top 10** in this order: primary email → bank(s) → phone carrier → Apple/Google ID → credit card → payroll/benefits portal (personal login) → Amazon → social media ×2 → utilities.
   For each one: log in → change password → use the generator (20+ chars) → save.
5. **Turn off** the browser's built-in password saving so there's one source of truth.

## Done looks like
- [ ] Master passphrase on paper, stored safely
- [ ] App on phone + laptop, 2FA on the vault
- [ ] 10 accounts with new, unique, generated passwords
- [ ] Line added to `mission/LOG.md`
- [ ] This item checked off in `BACKLOG.md`

**If you run out of time:** stop at email + bank + phone carrier. Those three protect everything else.
