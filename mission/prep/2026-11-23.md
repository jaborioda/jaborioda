# Prep: Turn on MFA (app or key, not SMS)

> The password manager (prep/2026-11-22.md) is still the top item and not done. Do that first. This one is ready for the block after it.

**Why it matters:** A stolen password alone can't get in once MFA is on. SMS codes can be stolen through SIM swaps, so use an authenticator app or a security key.

**Time:** ~45 min

## Pick an authenticator
- **Bitwarden Authenticator** or **Ente Auth** (free, backs up your codes): https://bitwarden.com/products/authenticator/ · https://ente.io/auth/
- Or **Google Authenticator** with cloud backup turned on
- Optional upgrade later: 2 YubiKeys (one main, one backup): https://www.yubico.com/

## Steps (in this order)
1. **Primary email**: Google https://myaccount.google.com/signinoptions/twosv · Outlook https://account.microsoft.com/security · Proton: Settings → Account → Two-factor
2. **Apple ID / Google account** (if not done in step 1): https://support.apple.com/en-us/102660
3. **Bank(s)**: Security settings in the app. If they only offer SMS, use it, but also set up a login alert.
4. **Phone carrier**: Add a **port-out PIN / number lock** (blocks SIM swaps). Search "<your carrier> number lock" on the carrier's own site.
5. For each account, **save the recovery/backup codes** in the password manager's notes for that entry.
6. Where an account offers it, **remove SMS as a fallback** once the app works.

## Done looks like
- [ ] Authenticator app installed, backup on
- [ ] MFA on email, Apple/Google, bank(s)
- [ ] Carrier port-out PIN / number lock set
- [ ] Recovery codes saved for each account
- [ ] Log line written (or just tell Claude in chat and it'll write it)
